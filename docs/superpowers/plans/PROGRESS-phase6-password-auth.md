## المراجعة النهائية (APPROVED — مفيش blocking)
- الدخول (موبايل+باسورد) بالحساب التجريبي شغّال؛ غلط البيانات → رسالة ودودة.
- إنشاء حساب: فحص رقم جديد + تأكيد OTP (1234) → الحساب بيتعمل **ويدخل فعلاً** بعدها.
- نسيت الباسورد: فحص وجود الحساب + OTP → باسورد جديد **بيدخل فعلاً**.
- سلة الزائر بتنجو بعد الدخول؛ redirect-after-login بيرجّع لـ `from`؛ العدّاد local (مفيش per-second cubit emit)؛ مفيش كود OTP-login قديم متبقّي.

## تجربة يدوية على الويب
- **دخول:** 01000000000 / 123456.
- **حساب جديد:** أي رقم 01 جديد + باسورد 6+ → كود 1234.
- **نسيت الباسورد:** 01000000000 → كود 1234 → باسورد جديد.

## متابعات مؤجّلة
- Supabase auth حقيقي + تشفير كلمة السر (bcrypt/argon)، خيار الإيميل، session persistence، rate-limiting، WhatsApp-OTP كبديل، تفعيل حماية routes (AuthGate) لما شاشات المالك تتعمل.
