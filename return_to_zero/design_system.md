# 🎨 WASALNI — Design System

> **التاريخ:** 2026-05-29 | **الحالة:** معتمد ✅
> المرجع الوحيد للتصميم. أي component فالتطبيق لازم يرجع للملف ده.
> **اللوجو:** `logo_wasalni.svg` (master) + `app_icons/` (أحجام جاهزة).

---

## 0. المبادئ
1. **السهولة** — لو حد عمره 60 سنة مش هيقدر يستخدمه، التصميم فشل.
2. **الثقة** — كل عنصر يطمّن اليوزر إن المعلومة صحيحة و موثوقة.
3. **التركيز المحلي** — القرية هي المركز.
- **عربي / RTL بالكامل.** استخدم `EdgeInsetsDirectional` مش `EdgeInsets`.

## 2. الخطوط (Typography) — Cairo

عبر `google_fonts` (Cairo). **مفيش خط أصغر من 14sp.** ممنوع italic فالعربي. line-height 1.6 للـ body.

| Style | الحجم | Weight | الاستخدام |
|---|---|---|---|
| Display | 28sp | 800 | عناوين الشاشات الكبيرة |
| Headline | 22sp | 700 | عناوين الأقسام |
| Title | 18sp | 700 | أسماء المحلات/الخدمات، عناوين الكروت |
| Body | 16sp | 400 | النصوص الأساسية |
| Caption | 14sp | 400 | البيانات الثانوية، المسافة، القسم |
| Label | 13sp | 600 | الـ badges، الـ tags (استثناء وحيد < 14) |

## 4. الاستدارة و الظل

**Border Radius:**
- الكروت: `16dp`
- الأزرار / الـ inputs: `12dp`
- الـ badges: `8dp`
- chips / pills: `999dp` (full)

**Elevation (ظل ناعم):**
- الكرت: `0 3px 12px rgba(8,47,61,0.10)`
- الشريط السفلي: `0 -2px 10px rgba(8,47,61,0.06)`

## 5. أهداف اللمس (Touch Targets)

- الحد الأدنى لأي عنصر قابل للضغط: **48×48dp**
- أزرار "اتصل" و "واتساب": **56dp**
- المسافة بين العناصر القابلة للضغط: **8dp** على الأقل

## 7. الكروت

### 7.1 كرت مقدم خدمة (Service)
1. صورة/غلاف (نسبة 4:5 أو غلاف 120dp) + gradient `primary→primaryDark` لو مفيش صورة
2. شارات فوق الصورة: ✓ موثّق (يمين أعلى) + ● مفتوح (يسار أسفل) — **أقصى 2**
3. الاسم (Title 18/700)
4. القسم + المسافة (Caption 14، `textSecondary`)
5. زرار **تواصل واتساب** full-width (whatsapp green)

### 7.2 كرت محل (Shop)
- نفس البنية + زرار **"شوف المنتجات"** (primary) بدل الواتساب المباشر
- شارة "في قريتك" لو نفس القرية

### 7.3 كرت منتج (Product)
1. صورة المنتج (4:5) أو placeholder بأيقونة القسم
2. اسم المنتج (Title 18/700)
3. **السعر** (Headline 22/800، `primary`) — "١٢٠ جنيه"
4. اسم المحل (Caption، clickable)
5. زرار **＋ أضف للسلة** (accent coral)

### 7.4 كرت نقل (Transport)
- أيقونة المركبة كبيرة على gradient
- الاسم + النوع + المنطقة
- زرّارين: واتساب (green) + اتصال (outline) جنب بعض

**قواعد عامة للكروت:**
- لو مفيش صورة: **Smart Placeholder** = خلفية بلون القسم + أيقونة كبيرة + الاسم.
- أقصى **2 badges** على الكرت فالـ feed. الباقي فصفحة التفاصيل.
- الكرت كله clickable.

## 8. الشارات (Badges) و الأقسام (Chips)

| الشارة | الشكل |
|---|---|
| ✓ موثّق | خلفية بيضا، نص `verified` `#1B4965` — أو العكس على الصور |
| ● مفتوح دلوقتي | خلفية `success`، نص أبيض |
| 📍 على بعد X | pill `surfaceAlt`، نص `textSecondary` |
| ⭐ في قريتك | pill `#FFF1E8`، نص `accent` |
| 👑 برايم | pill `#FFF6DD`، نص `#B8860B` |

**Chips الأقسام:** pill، النشط = `primary` fill + نص أبيض، غير النشط = أبيض + border. كل قسم له **أيقونة** قبل اسمه (صيانة 🔧، حلاقة ✂️، بقالة 🛒، نقل 🛺...).

---

## 9. الإدخال و البحث

- حقل: خلفية بيضا، border `1.5px #DCE6EA`، radius 12، padding 12-14.
- focus: border `primary`.
- خطأ: border `error` + نص أحمر صغير تحت الحقل (مش modal).
- البحث: أيقونة 🔍 + placeholder بعامية: "ابحث عن محل أو خدمة..."

---

## 10. الشريط السفلي (Bottom Nav)

**4 تابات فقط:**
| الأيقونة | الاسم |
|---|---|
| 🏠 | الرئيسية (Feed) |
| 🔍 | البحث (+ الأقسام) |
| ❤️ | المفضلة |
| 👤 | حسابي |

- ارتفاع 64dp، كل tab ≥ 56dp، أيقونة 24dp، نص 12sp.
- Active: `primary` + bold. Inactive: `textDisabled`.

---

## 11. الحالات (States)

- **Loading:** Skeleton screens (مش spinners)، shimmer خفيف RTL، يشبه التصميم النهائي بـ `surfaceAlt`.
- **Empty:** أيقونة/رسمة + نص عامية ("محلش حاجة هنا لسه") + اقتراح action.
- **Error:**
  - No internet: 📡 + "مفيش نت، اتأكد من الاتصال" + زرار retry 56dp.
  - Server: "حصلت مشكلة عندنا، جرّب بعد دقيقة" + retry.
  - Validation: نص أحمر صغير تحت الحقل.

| Success | "تمام! اتحفظ" | "تم الحفظ بنجاح" |

**أسماء الأقسام = فصحى محايدة** (للتنظيم/البحث): مأكولات، ملابس، أدوات منزلية، خدمات، صحة، إلكترونيات، حرفيين، نقل.

## 13. اللوجو

- **Master:** `logo_wasalni.svg` (الواو كطريق + نقطة بداية مرجانية + حلقة وجهة).
- **App icons:** `app_icons/icon_{16..1024}.png`.
- خلفية الأيقونة تركوازي (قريب من `primary`). فالأحجام الصغيرة جداً (≤32) السيلويت يكفي بدون الخط المنقّط.
- **Lockup:** الأيقونة + كلمة "وصلني" (Cairo 800، `primary`).
- **Clear space** حول اللوجو ≥ نصف ارتفاع الأيقونة.

---

## 14. القيود التقنية

- Flutter + Material 3 كأساس بتخصيصات.
- خط Cairo عبر `google_fonts`.
- RTL إجباري على مستوى `MaterialApp`.
- يشتغل كويس على 2GB RAM و نت 3G.
- صور مرفوعة: ضغط على الـ client، حد أقصى ~1MB.
- Lazy loading للـ feed، ~20 عنصر/batch.
- State management: **Bloc**.

---

## 15. ملاحظات للتنفيذ (Flutter)

- اعمل `AppColors`, `AppTextStyles`, `AppSpacing`, `AppRadius` كـ constants.
- اعمل `ThemeData` مركزي يقرأ من التوكنز دي.
- كل component (`ShopCard`, `ServiceCard`, `ProductCard`, `TransportCard`, `WasalniButton`, `TrustBadge`, `CategoryChip`, `SearchField`, `EmptyState`, `ErrorState`, `SkeletonCard`) = widget مستقل قابل لإعادة الاستخدام.
- استخدم `EdgeInsetsDirectional` و `AlignmentDirectional` دايماً (RTL).
