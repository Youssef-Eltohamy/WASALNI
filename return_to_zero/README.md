## ايه هو الفولدر ده؟

ده فولدر دراسة كاملة عن **كل المنصات اللي قدمت فكرة شبيهة بـ WASALNI** (اكتشاف محلي، دليل تجاري، خدمات، حرفيين) — مع تحليل ايه نجح، ايه فشل، و ايه ينفع لـ WASALNI تحديداً (قرية مصرية، كفر المقدام، **محافظة الدقهلية**).

**الغرض:** نبني WASALNI على قاعدة معرفية قوية، مش على افتراضات. نتعلم من 25+ تطبيق حقيقي قبل ما نكتب سطر كود واحد.

**حجم البحث:**
- 15 ملف
- ~450 KB من النص المنظم
- ~75,000 كلمة (~200 صفحة قراءة)
- 9 research agents اشتغلوا فمتوازي + بحث مباشر

- 100+ مصدر موثّق

## 🎁 أهم 10 خلاصات (Spoilers — للقارئ المستعجل)

> هذه ملخصات للقارئ المستعجل. التفاصيل و الاستدلال فالملفات نفسها.

### 🎯 الفرص الحقيقية

1. **السوق متروك:** مفيش تطبيق consumer مصري ناجح للـ local discovery دلوقتي. الفرصة موجودة.
2. **البنية التحتية بتتحسن:** حياة كريمة + 4G/5G expansion = "highway with no cars" — WASALNI يقدر يكون الـ "first car".
3. **63% من ريف مصر online** = ~33 مليون مستخدم محتمل. السوق ضخم.
4. **Hyperlocal precision = الـ moat الوحيد** اللي Google و Facebook ميقدروش يقلدوه.
5. **Field team door-to-door + Trust nodes موجودة بالفعل** = أهم الـ assets.

### 🚨 المخاطر الكبيرة (والأخطاء الحالية)

6. **المنافس الحقيقي = HABIT (واتساب + فيسبوك)، مش app آخر.** WASALNI لازم يكون **أحسن بكتير**، مش بس "شوية".
7. **WhatsApp = العمود الفقري** — مش feature. الـ MVP لازم يكون فوقه، مش بديل ليه.
8. **الـ pure directory model ميت** عالمياً (Yell، Pages Jaunes، Citysearch). WASALNI محتاج يكون أكتر من قائمة.
9. **حالة WASALNI الحالية بتقع فـ 11 من أصل 18 anti-pattern** (راجع synthesis_anti_patterns.md). الـ rebuild ضرورة، مش رفاهية.
10. **74% من الـ startups بتموت قبل PMF بسبب over-engineering** — WASALNI دلوقتي فالمنطقة دي تماماً.

### 🔥 التوصية الكبرى (المختصرة)

**60 يوم من الـ Manual MVP على WhatsApp قبل ما تكتب سطر Flutter جديد:**
1. WhatsApp Channel "وصلني كفر المقدام"
2. تجميع 30-50 حرفي يدوياً (سباك، كهربائي، نجار)
3. نشر صور و بيانات يومياً
4. قياس الـ engagement الحقيقي
5. القرار: نكمل / نبيفّت / نقفل

لو نجحت، **نبني MVP بسيط جداً (4 شاشات فقط)** بـ:
- ✅ Service-first (مش Shop-first)
- ✅ Phone OTP (مش Email)
- ✅ Hybrid WhatsApp model
- ✅ Free لـ 12 شهر
- ✅ كفر المقدام فقط

## 📐 جدول القرارات المبدئية (راجع decisions_needed.md للتفاصيل)

| القرار | التوصية | السبب الرئيسي |
|---|---|---|
| المسار قبل MVP | **Manual MVP (60 يوم WhatsApp)** | الـ validation قبل الـ code |
| نوع الـ Supply | **Services / حرفيين فقط** | الـ pain أوضح، Vezeeta proved this |
| Auth | **Phone OTP فقط** | الريف phone-based، مش email |
| WhatsApp | **Hybrid (deep-link + tracking)** | المنافس + القناة فنفس الوقت |
| Existing code | **Sideline (branch منفصل)** | القرار يستنى الـ Manual |
| Categories MVP | **البيت فقط** (سباك، كهربائي، نجار، حداد، نقاش) | الـ pain متكرر، competition ضعيفة |
| Monetization | **مجاني 12 شهر** | كل الـ research قاطع |
| Geography | **كفر المقدام فقط 6-12 شهر** | density > coverage |
| Spec Kit | **أوقف 90 يوم** | ceremony بدون فائدة لـ solo founder |
| Web Fallback | **Mobile + Web Profile Pages** | SEO + WhatsApp shares |
| Field Team | **نزل بنفسك قبل ما تعتمد** | غير مختبر |
| Reviews | **مؤجّلة 100%** | drama اجتماعي + قانوني |
